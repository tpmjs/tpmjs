# @tpmjs/tools-railway

## 0.2.0

### Minor Changes

- feat: add official AI agent tools for GitHub, Vercel, Cloudflare, and Railway

  New tool packages for AI agents using AI SDK v6:

  - **@tpmjs/tools-github** - GitHub REST API (repos, issues, PRs, commits, releases, gists, actions)
  - **@tpmjs/tools-vercel** - Vercel API (deployments, projects, domains, env vars, logs, usage)
  - **@tpmjs/tools-cloudflare** - Cloudflare API (zones, DNS records, Workers, KV)
  - **@tpmjs/tools-railway** - Railway GraphQL API (projects, services, deployments, logs, variables)

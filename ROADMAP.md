# Roadmap

The living roadmap is tracked in GitHub, where it stays current and anyone can weigh in:

- **[🗺️ Roadmap issue #116](https://github.com/tpmjs/tpmjs/issues/116)** — the checklist, updated as work lands.
- **[Milestones](https://github.com/tpmjs/tpmjs/milestones)** — grouped, dated goals.
- **[Issues](https://github.com/tpmjs/tpmjs/issues)** — everything proposed or in flight.

## Vision

TPMJS is the **protocol-agnostic tool layer for AI agents**. You curate a tool collection once, and TPMJS serves that exact set through every surface at once — **CLI · MCP · REST · SDK · Skill**. There's no MCP-vs-CLI-vs-REST war to pick a side in; each is simply better in a different context. Curation, health-scoring, and sandboxed execution are features layered on top of every protocol.

## Current focus

We're on an **[OSS Excellence](https://github.com/tpmjs/tpmjs/milestones) push** — making TPMJS an exemplary open-source project across eight dimensions:

1. Instant comprehension
2. 5-minute first success
3. Every surface documented (CLI · MCP · REST · SDK · Skill)
4. A frictionless contributor on-ramp
5. Trustworthy, provenance-gated releases
6. Green everything (CI, real test coverage, no placeholders)
7. Transparent roadmap & governance
8. Delight (examples, demos, a "wow" moment)

## How to influence it

Open an issue with the idea, or comment on the [roadmap issue](https://github.com/tpmjs/tpmjs/issues/116). Good proposals get scheduled; great PRs get merged. See [CONTRIBUTING.md](./CONTRIBUTING.md) and [GOVERNANCE.md](./GOVERNANCE.md).

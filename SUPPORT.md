# Support

Thanks for using **TPMJS** — the protocol-agnostic tool layer for AI agents (one collection, served as CLI · MCP · REST · SDK · Skill). Here's how to get help.

## Documentation first

Most questions are answered in the docs:

- **[Docs & guides](https://tpmjs.com/docs)** — quickstart, per-surface guides (CLI, SDK, MCP, REST, Skills), tutorials, and API reference.
- **[Quickstart](https://tpmjs.com/docs/quickstart)** — get to a first working call in a few minutes.
- **Package READMEs** — each package under [`packages/`](./packages) documents its own usage.

## Ask the community

- **[Discord](https://discord.gg/KuJRBCn89c)** — the fastest place for usage questions, help, and discussion.

## Report a bug or request a feature

- **[Open an issue](https://github.com/tpmjs/tpmjs/issues/new/choose)** using the bug-report or feature-request template.
- Search [existing issues](https://github.com/tpmjs/tpmjs/issues) first — someone may have hit the same thing.
- For a tool you want added to the registry, use the **tool request** template.

## Security

**Do not open a public issue for security vulnerabilities.** Follow the process in [SECURITY.md](./SECURITY.md).

## Contributing

Want to help? See [CONTRIBUTING.md](./CONTRIBUTING.md) for local setup and the contribution flow, and the [roadmap](./ROADMAP.md) for where the project is headed.

## Contact

For conduct concerns or anything not covered above: **hello@tpmjs.com**.
